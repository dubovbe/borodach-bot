# Работа над проектом

## Согласованная основа

Перед изменениями читать docs/superpowers/specs/2026-11-05-borodach-bot-design.md. Описание согласовано 2026-11-06, шаг начала записи 30 минут. TypeScript + Cloudflare Workers + Neon PostgreSQL. Бюджет 0 рублей, собственные тестовые данные, один барбершоп. Не подключать боевой YCLIENTS.

## Общение и этапы

- Общаться с пользователем по-русски, объяснять технические решения простыми словами.
- Работа итеративная: согласованный план, небольшой законченный этап, проверка, коммит и отправка в GitHub, отчёт. Останавливаться на границах согласованных этапов для обсуждения следующего.
- До кода подготовить и согласовать план через Superpowers writing-plans. Новые существенные правила продукта не придумывать молча.
- Перед этапом давать краткую оценку: сложность низкая/средняя/высокая; достаточно ли текущей модели; конкретная причина возможного усиления. Не утверждать, что более сильная модель обязательна, и не обещать точный расход лимитов. Самостоятельно модель не переключать.
- Настройки моделей/уровня рассуждений субагентов отдельно не согласованы. Не распространять выбор модели текущего чата на работников без основания.

## Оркестрация и экономия

- Основной агент координирует работу и отвечает за целостность результата.
- По мере необходимости делегировать небольшие задачи с конкретным результатом и проверкой. Не запускать постоянно работающую команду и не делегировать ради самого делегирования.
- Передавать работнику только нужную спецификацию, файлы и критерии готовности. По возможности использовать изолированный контекст, не копировать всю переписку.
- Не создавать вложенные команды без конкретной необходимости. Не опрашивать агентов частыми короткими вызовами.
- Проверка субагента не заменяет собственную проверку изменений основным агентом.
- Agency Agents пока не подключён. Найден вероятный источник https://github.com/msitarzewski/agency-agents, личность источника ещё не подтверждена пользователем. Не устанавливать весь каталог или менять глобальные настройки автоматически. Superpowers доступен.

## Git и данные

- Делать отдельный осмысленный коммит на завершённый этап. Не коммитить несвязанные изменения.
- Отправлять завершённые этапы в согласованный репозиторий GitHub. Не считать локальный коммит опубликованным без проверки удалённого результата.
- Пользователь выбрал публичный репозиторий для портфолио 2026-11-06. Предложено имя borodach-bot. Пока удалённый репозиторий не создан/не выбран, не использовать другой репозиторий без уточнения.
- Не включать токены, пароли, .env, локальные секреты Wrangler, рабочие базы и резервные копии в Git.
- Откат кода не равен откату базы. Изменения схемы сопровождать порядком восстановления.
- До заявления о готовности выполнить проверки, соответствующие изменению, и сообщить фактический результат. Для документации достаточно проверки diff и ссылок; приложение не тестировать, пока его нет.
