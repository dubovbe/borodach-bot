# Отложенные улучшения

## Подписи кнопок на телефоне

Зафиксировано 9 ноября 2026 по ручной проверке аккаунтом 2 на iPhone: верхний ряд из пяти кнопок обрезает подписи («Мои…», «Наст…», «Рабо…», «Стат…», «Запи…»). Сначала исправление было отложено. Затем пользователь вернулся к нему, попросил найти референсы на GitHub и добавить эмодзи после исправления раскладки. Пользователь выбрал вариант A после просмотра макетов. [Короткий дизайн для подтверждения](superpowers/specs/2026-11-09-mobile-menu-design.md); код бота пока не менялся. [Референсы и подходы](ui-references.md).

При следующей работе над интерфейсом подобрать короткие понятные названия и уменьшить число кнопок в ряду: ориентир — две короткие или одна длинная. Проверить главное меню и карточки на настоящем телефоне, в том числе при увеличенном размере шрифта. Действия и права ролей сохранить. Это пожелание для будущего этапа, сейчас поведение бота не менялось.
