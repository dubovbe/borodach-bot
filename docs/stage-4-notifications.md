## Согласованная основа

Объём — [этап4 плана](superpowers/plans/2026-11-06-borodach-bot.md) и [спецификация](superpowers/specs/2026-11-05-borodach-bot-design.md). Разработчик Sol Medium, проверяющий Sol High, основной чат остаётся выбранным пользователем. Нативный agent_type теперь доступен: для этого этапа выбраны Backend Architect и Code Reviewer; предыдущие ручные проверки TOML не отменяются.

Бизнес-операция фиксируется вместе с outbox. Внешняя отправка идёт после commit. Каждая попытка получает lease/token; просроченный отправитель не может перезаписать результат нового. 429 учитывает retry_after, временный сбой повторяется с ограниченным backoff,403 отмечает недоступность получателя без отмены визита. Уведомление сотруднику дедуплицируется и не порождает цепочку ошибок само на себя. Повтор сообщения при сетевой неопределённости возможен; повтор бизнес-операции запрещён.

Durable Object хранит следующий срок и generation, не клиентов. Arm только приближает срок; перед потенциально падающей работой ставится защитный alarm. Новое раннее arm во время await не теряется при завершении старого запуска. Одна активация обрабатывает максимум5 заданий/сообщений суммарно. Cron ensure проверяет только хранилище DO, при простое не обращается к Neon.
