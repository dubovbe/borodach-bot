## Границы проверки и последующие действия

Статические проверки доказывают полноту преобразования и копирования, но не качество каждого совета и не автоматическое обнаружение роли клиентом Codex. 2026-11-06 отдельно проверен запуск субагента с явным чтением установленной инструкции Code Reviewer; результат и состав команды — [agent-team.md](agent-team.md). Текущий интерфейс spawn_agent не предоставляет параметра agent_type, поэтому нативный выбор установленной роли не проверен и не обещается.

В оригинальном Agents Orchestrator предлагается автономный полный конвейер с повторными dev/QA-циклами. Это не совпадает с требованием пользователя обсуждать этапы и экономить лимиты. Перед использованием нужно определить применимые обязанности и явно передавать ограничения проекта; установка не означает согласия на выполнение всех инструкций всех ролей. Исходные роли оставлены без изменений для проверки подлинности.

Названия ролей не гарантируют соответствия стеку: например, Senior Developer содержит специализацию Laravel/Livewire. Подбор по содержанию, а не только названию, выполняется следующим этапом. Модели работников отдельно не согласованы, автоматическое распределение моделей не включалось. Superpowers продолжает определять согласованный процесс.

## Восстановление

Точную версию можно восстановить из указанного коммита, повторив конвертацию и установку, затем сравнить SHA-256 с манифестом. Перед будущей заменой изменённых пользовательских ролей сохранять их отдельно. Не удалять весь каталог `~/.codex/agents`, поскольку там могут появиться роли других источников.
