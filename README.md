# Бородач — Telegram-бот записи

Учебный проект для одного барбершопа: клиенты записываются через кнопки в Telegram, барберы подтверждают заявки и управляют визитами, админ настраивает услуги, ранги и графики.

## Статус

Согласовано описание первой версии. Реализация приложения и размещение ещё не начаты.

- TypeScript, Cloudflare Workers, Neon PostgreSQL.
- Бюджет: 0 рублей в пределах бесплатных квот; доступность регистрации предстоит проверить.
- Собственные тестовые данные. Подключения к боевому YCLIENTS нет.
- Шаг начала записи: 30 минут.
