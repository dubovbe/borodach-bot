# Бородач — Telegram-бот записи

Учебный проект для одного барбершопа: клиенты записываются через кнопки в Telegram, барберы подтверждают заявки и управляют визитами, админ настраивает услуги, ранги и графики.

## Статус

Описание и план первой версии согласованы. Техническая проверка размещения (этап 1) выполнена в ветке `chore/stage-1-deployment-probe`: опубликован Worker, подключён Telegram webhook, проверены Neon HTTP/интерактивная транзакция и удалённый alarm. Временные команды диагностики удалены. Проверки: 14 Worker-тестов + 3 CLI, TypeScript, сборка, независимое ревью и remote smoke. Ограничения замеров CPU/расхода и факт отдельного пика около 26 мс — в [отчёте](docs/deployment.md). Этапы 2–11 не начаты; функций записи пока нет.

- TypeScript, Cloudflare Workers, Neon PostgreSQL.
- Бюджет: 0 рублей в пределах бесплатных квот; аккаунты Cloudflare и Neon созданы, тарифы не повышались.
- Собственные тестовые данные. Подключения к боевому YCLIENTS нет.
- Шаг начала записи: 30 минут.
